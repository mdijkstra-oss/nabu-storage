# Extra Tool Notes

## Codebook & Memory Tools

**Codebook:**
- Read: `get_project_codebook({ projectId })`
- Write: `edit_codebook({ project_id, old_text, new_text })` or `replace_codebook({ project_id, content })`

**Memory:**
- Read: `get_memory({ projectId })`
- Write: `edit_memory({ project_id, old_text, new_text })` or `replace_memory({ project_id, content })`

Codebook stores methodology decisions and settings. Memory stores cross-session observations and researcher preferences.
