# Preferences

This file is where Nabu keeps what it has learned about how you work. It is read at the start of every conversation and written to when something is worth remembering — that you write in British English, that interviewer speech should never be coded, that a chart belongs at the end of a document rather than the top.

You can write here yourself. Anything you add carries the same weight as anything Nabu wrote, so put your standing instructions here, correct what has been misremembered, and delete what no longer holds.

This file is not searched or quoted like the rest of your documents, and it cannot be renamed or deleted.
