## Coding Preferences

### Density

- [ ] **Conservative** — Only clear, unambiguous instances. When in doubt, don't code. Prioritizes precision.
- [ ] **Liberal** — Include ambiguous cases. Code anything that plausibly fits. Prioritizes recall.

### Overlap Policy

Can the same text segment receive multiple codes?

- [ ] **Yes, encouraged** — Multi-coding captures complexity
- [ ] **Yes, but minimize** — Only when genuinely distinct dimensions
- [ ] **No** — Each segment gets one code per category

### Granularity

What's the typical unit of analysis?

- [ ] **Phrase/clause** — Key terms, specific expressions
- [ ] **Sentence** — Complete thoughts
- [ ] **Paragraph** — Full arguments, extended ideas
- [ ] **Mixed** — Varies by code type
